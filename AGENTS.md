# Правила работы над проектом (Greek Exam B1)

1. **Язык общения**: Всегда общайся с пользователем **на русском языке**.
2. **Обязательное делегирование написания кода китайским моделям**:
   - Ты выступаешь в роли **Архитектора, Техлида и Ревьюера**.
   - Всю работу по написанию нового кода, верстке компонентов и крупному рефакторингу **делегируй китайским флагманским моделям** через скилл `chinese-coder` (`node .agents/skills/chinese-coder/scripts/delegate.mjs`).
   - Выбирай роль модели под задачу:
     - `--role frontend` (Kimi K3 / K2.5) — для UI, дизайна, React-компонентов и тренажёров.
     - `--role logic` (DeepSeek V4 / V3) — для бизнес-логики, хуков, парсинга словарей и стейта.
     - `--role reasoner` (DeepSeek R1) — для сложных алгоритмов (например, интервального повторения SRS, сложной проверки грамматики).
     - `--role qwen` (Qwen3-Coder) — для строгой типизации TypeScript.
   - После того как модель сгенерировала и применила код (`--apply`), **обязательно проверь результат** (запусти сборку/проверку типов `tsc` и посмотри дифф).
   - Если в `.env` ещё не вписан API-ключ, напомни пользователю вставить `OPENROUTER_API_KEY` (или `DEEPSEEK_API_KEY`) в файл `.env`.
